# Contributing

Contributions, bug reports, and pull requests are welcome!

## Workflow

1. Fork this repository and clone your fork locally.
2. Load the repository folder in `chrome://extensions` using **Load unpacked**.
3. Make your changes and test across:
   - Home feed single posts and multi-slide carousels
   - Standalone post pages (`/p/<shortcode>/` and `/<username>/p/<shortcode>/`)
   - Profile grid hover buttons and **Download All** bulk downloads
   - Reels and Stories/Highlights
4. Run `npm run check` to verify there are no syntax errors.
5. Submit a Pull Request with a clear description of the issue and fix.
